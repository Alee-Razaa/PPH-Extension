## 1. Goals and scope

### 1.1 Must have
- Runs only while Chrome is open. No server, no cloud, no account.
- Checks `https://www.peopleperhour.com/freelance-jobs` on a **user adjustable interval**: every 3 min, every 10 min, a random 5 to 10 min range, or any custom value from 2 to 60 min. Changes apply immediately, without reloading the extension. See 4.4.
- Full page reload each check. Wait 20 seconds (adjustable) for the page to settle before reading.
- Reads the **top 5** jobs (adjustable 3 to 20).
- Alerts when a job is **new** (never seen before) and its age is under the fresh window: 10 minutes by default, automatically widened so no job posted between two checks is missed. See 4.4.
- Alert = desktop notification + sound.
- Installed locally with Load unpacked. Never published.
- Never alerts the same job twice.
- Does nothing when offline, when the page is unresponsive, or when the tab is gone.
- Stays on this one page. No crawling other pages.

### 1.2 Should have
- Popup with live status, countdown to next check, and the last 5 jobs seen.
- Options page: interval, freshness window, filters, sound, volume, test buttons.
- Keyword, budget, proposal-count and remote filters.
- Badge on the toolbar icon showing state at a glance.
- Local activity log (last 50 cycles) for debugging.

### 1.3 Out of scope
- Auto applying or auto bidding. Notification only.
- Logging in, storing credentials, or touching the user's PPH account.
- Scraping page 2 and beyond.
- Syncing across machines.

### 1.4 Design principle
**Be a quiet instrument, not a machine that hammers the site.** One page load per 5 to 10 minutes, jittered, with a hard hourly cap. If the site pushes back, stop and tell the user.

## 2. Platform facts (verified 2026)

These are the constraints the design must respect. Every one of them was checked against current Chrome docs, not assumed.

| Fact | Value | Impact on design |
|---|---|---|
| Manifest version | MV3 only. MV2 is dead. | Service worker, not background page |
| Service worker idle timeout | Terminated after **30 seconds** of inactivity | **Never `await sleep(20000)` inside the worker.** See 4.2 |
| Single operation hard cap | 5 minutes | Cycle must be event driven, not one long function |
| What resets the idle timer | Receiving an event, calling a `chrome.*` API, messages from an offscreen document | We wake on messages, not on timers |
| Global variables | Lost on worker shutdown | All state in `chrome.storage` |
| `chrome.alarms` minimum | **30 seconds** (`0.5` minutes). Values below are warned and not honored | Our 2 to 60 min interval is safe. The 90 s watchdog is safe. Re-arm delays are floored at 30 s |
| Alarms and sleep | An alarm does not wake a sleeping device. Missed alarms fire on wake | One catch-up cycle after wake, not a burst. Handle this |
| `alarms.persistAcrossSessions` | Chrome 150+ | Do not rely on it. Re-arm on `onStartup` and `onInstalled` |
| `storage.local` quota | 10 MB (5 MB on Chrome 113 and older) | Plenty. Prune anyway |
| `storage.session` quota | 10 MB (1 MB on Chrome 111 and older) | Used for tab id and cycle lock |
| `storage.sync` quota | ~100 KB total, 8 KB per item, 512 items | Not used. This is a local tool |
| Offscreen documents | **One at a time** per profile. Chrome 109+ | Single audio document, reused |
| Offscreen `AUDIO_PLAYBACK` | **Auto closes after 30 seconds of no playback** | No manual close needed. Just create if missing |
| Remote code | Forbidden. All JS must ship in the package | No CDN, no `eval`, no remote scripts |
| Content script world | Isolated. Cannot read page globals like `window.PPHReact` | Read the `<script>` tag's **text** instead. See 3.2 |
| Content scripts and ES modules | Manifest `content_scripts.js` files are classic scripts. `export` is a SyntaxError | One classic bootstrap that calls `import(chrome.runtime.getURL(...))`. Imported files must be in `web_accessible_resources`. See 6 |
| Tabs opened before the extension loaded | Have no content script until they reload | Never require a content script reply before reloading. See 8.2 |
| `node --test <dir>` | Node 22+ treats arguments as globs. A bare directory fails | Test script uses `"tests/**/*.test.js"` |

## 3. Site contract (verified live)

Everything here was confirmed by inspecting the live page on 2026-09-16. Treat this section as the contract the parser is written against. If any of it breaks, the parser must degrade, not crash.

### 3.1 Page behaviour
- `https://www.peopleperhour.com/freelance-jobs` is **server rendered**. No XHR fires on load to fetch the job list.
- Therefore **a full reload is the only refresh path.** This is not a workaround, it is the design.
- Default sort is already `latest`. No clicking required.
- 20 jobs per page. Pagination is plain links `?page=2` ... `?page=37`.
- Canonical: `https://www.peopleperhour.com/freelance-jobs`

### 3.2 Primary data source: the inline state script

The page ships a ~195 KB inline `<script>` whose text begins with `window.PPHReact`. It contains:

```
window.PPHReact={};
window.PPHReact.initialState={ ... valid JSON ... };
window.PPHReact.data={ ... JS object literal, NOT JSON ... };
window.PPHReact.serverTime='1789584228635';
```

**Three rules:**
1. Do **not** `JSON.parse` the whole script. It is not JSON.
2. Do **not** read `window.PPHReact` from a content script. Isolated world, it is invisible.
3. Do read the script element's `textContent` and slice out just the `initialState` value.

Working extraction (tested live):

```js
const el = [...document.querySelectorAll('script')]
  .find(s => !s.src && (s.textContent || '').trim().startsWith('window.PPHReact'));

const raw = el.textContent;

const m = raw.match(
  /window\.PPHReact\.initialState\s*=\s*([\s\S]*?);\s*window\.PPHReact\.data\s*=/
);
const state = JSON.parse(m[1]);                                  // valid

const serverTimeMs = Number(
  (raw.match(/window\.PPHReact\.serverTime\s*=\s*'(\d+)'/) || [])[1]
);
```

### 3.3 State shape

```
state.freelanceJobs.main.data          -> [{ id: "4521929", type: "projects" }, ... 20 items]
state.freelanceJobs.main.meta          -> { total-pages, total-items, current-page, applied_filters }
state.freelanceJobs.main.meta.applied_filters.sort  -> "latest"
state.freelanceJobs.featured.data      -> may be non empty. IGNORE IT.
state.freelanceJobs.completed.data     -> may be non empty. IGNORE IT.
state.entities.projects[id].attributes -> the job itself
```

`main.data` is in **listing order, newest listing first**: project ids strictly descending. Index 0 to 4 is the 5 newest listings.

**Correction (live check 2026-09-17, Phase 1):** revision 1 said the list is strictly descending by `posted_dt`. It is not. Job `4522017` (posted `09:02:26`) was listed above `4522015` (posted `09:04:22`). A job can reach the top of the list a few minutes after its `posted_dt`, so its age at first sight can already be a few minutes. Phase 3 must account for this: see the risk register row "Job listed late".

### 3.5 The timestamp trap (most important single item in this spec)

`posted_dt` is a **UTC wall clock** string, format `YYYY-MM-DD HH:mm:ss`, **with a space and no timezone suffix**.

`Date.parse("2026-09-16 18:39:37")` in Chrome treats it as **local** time. In Asia/Karachi (UTC+5) that is a **5 hour error**, and the extension would either alert on nothing or alert on everything.

Correct:

```js
const postedMs = Date.parse(posted_dt.replace(' ', 'T') + 'Z');
```

Use `serverTime` as "now", not `Date.now()`. It comes from the same page load, so it removes user clock skew entirely:

```js
const ageMin = (serverTimeMs - postedMs) / 60000;
```

Verified: top job `2026-09-16 18:39:37`, serverTime `1789584228635` -> 4 minutes, and the page itself rendered "4 minutes ago". Exact match.

Re-verified in Node 24 on Windows (rev 2):

| Expression | UTC | Asia/Karachi | America/Los_Angeles |
|---|---|---|---|
| `Date.parse('2026-09-16 18:39:37')` (wrong) | 1789583977000 | 1789565977000 | 1789609177000 |
| `Date.parse('2026-09-16T18:39:37Z')` (right) | 1789583977000 | 1789583977000 | 1789583977000 |

Age at that `serverTime`: `4.19` minutes. `1789583977000` is the known value the U1 test asserts.

### 3.6 Fallback: DOM parsing

Class names are CSS-module hashed with a `⤍Component⤚hash` suffix, for example `item--container⤍ListItem⤚2wpiz`. **The hash changes on every deploy.** Always prefix match.

| What | Selector |
|---|---|
| Job card | `[class*="item--container"]` (20 per page) |
| Title + link | `a[class*="item__url"]` (absolute href) |
| Description | `[class*="item__desc"]` |
| Price | `[class*="card__price"]` |
| Poster | `[class*="card__username"]` |
| Badge | `[class*="etiquettes--"]` |
| Footer meta | `[class*="card__footer-left"]` |

Footer spans in order: `["4 minutes ago", "8 proposals", "Remote", "Remote"]`.

The time is **relative text only**. No `datetime` attribute. Moment style strings observed:
`a few seconds ago`, `a minute ago`, `N minutes ago`, `an hour ago`, `N hours ago`, `a day ago`.

These are moment.js `fromNow()` buckets, and they are **rounded**:

| Real age | Text |
|---|---|
| 0 to 44 s | `a few seconds ago` |
| 45 to 89 s | `a minute ago` |
| 90 s to 44 min | `N minutes ago`, N = rounded minutes |
| 45 to 89 min | `an hour ago` |
| 90 min to 21 h | `N hours ago`, rounded |
| 22 to 35 h | `a day ago` |

Client clock skew can also produce `in a few seconds`. Treat it as 0.

Consequences:
- `relToMs(text)` returns the bucket's representative age. Unknown text returns `UNKNOWN_AGE_MS` (99 days, finite, never fresh).
- Comparing our parsed age to the page text needs tolerance: ±1 minute for minute buckets, ±30 minutes for hour buckets. The page text was also rendered about 20 s before we parse. This is `ageMatchesText` in `core/time.js`. Never compare with strict equality.
- Job URLs end in the numeric project id. `idFromUrl(href)` extracts it so the DOM fallback uses the **same dedupe key** as the state parser. Confirm the URL shape when capturing the fixture (22.1).

### 3.7 Blocked / walled page detection

Treat the page as blocked when **all** of these hold:
- `document.readyState === 'complete'`
- no `window.PPHReact` state script is present
- `document.querySelectorAll('[class*="item--container"]').length === 0`
- and either the title matches `/just a moment|attention required|access denied|sign in|log in/i`, or the body contains a captcha iframe.

On `BLOCKED`: stop the schedule, set badge to `!`, fire one notification, and require the user to resume manually from the popup. Never retry in a loop.

## 4. Architecture

### 4.1 Components

```
┌─────────────────────────────────────────────────────────┐
│  background.js  (MV3 service worker, event driven)      │
│  - owns the schedule (chrome.alarms)                    │
│  - owns dedupe store, settings, stats                   │
│  - decides what is fresh, fires notifications           │
│  - NEVER sleeps. Wakes on: alarm | message | tab event  │
└───────────┬──────────────────────┬──────────────────────┘
            │ tabs.reload          │ runtime.sendMessage
            ▼                      ▲
┌─────────────────────────────────┴──────────────────────┐
│  content.js  (isolated world, on /freelance-jobs*)     │
│  - on load: waits the settle window                    │
│  - parses state script -> top 5 jobs                   │
│  - falls back to DOM parsing                           │
│  - pushes the result up to the worker                  │
└────────────────────────────────────────────────────────┘
            │ runtime.sendMessage('PLAY_SOUND')
            ▼
┌────────────────────────────────────────────────────────┐
│  offscreen.html / offscreen.js                         │
│  - the only place audio can play under MV3             │
│  - auto closes 30s after playback ends                 │
└────────────────────────────────────────────────────────┘

  popup.html  -> status, countdown, last 5 jobs, pause, check now
  options.html -> intervals, filters, sound, test, log, reset
```

### 4.2 The one architectural decision that matters

**The 20 second settle wait lives in the content script, not in the service worker.**

Reason: the worker is killed after 30 seconds idle. A bare `await sleep(20000)` in the worker is 20 seconds of no API calls, which puts us one hiccup away from being terminated mid cycle, losing the in-flight state.

So the flow is inverted. The worker fires and forgets:

```
worker: alarm -> precheck -> set cycle lock {tabId} -> arm 90s watchdog -> tabs.reload(tabId) -> DONE, worker may die
page:   reloads -> content.js -> HELLO (am I the monitor tab in a cycle?) -> no: do nothing
                                                                        -> yes: settle 20s -> readiness -> parse -> JOBS
worker: wakes on JOBS -> sender.tab.id matches lock? -> re-validate -> compare -> alert -> clear lock -> schedule next
```

The worker is alive for maybe 300 ms per cycle instead of 25 seconds. This is the correct MV3 shape and it is also cheaper on battery.

The **watchdog alarm** (90 s) is the safety net. If the message never arrives, the watchdog fires, marks the cycle `UNRESPONSIVE`, clears the lock, applies backoff, and schedules the next tick. Without it a dead page would freeze the schedule forever.

### 4.3 Monitor tab policy

Reloading the tab the user is reading would destroy their scroll position and any half typed proposal.

**Default: the extension owns a pinned tab.**
- Popup has "Open monitor tab". It opens `https://www.peopleperhour.com/freelance-jobs` pinned, stores `monitorTabId` in `chrome.storage.session`.
- On `chrome.tabs.onRemoved` matching that id: clear it, set status `NO_TAB`, badge `-`, and offer to reopen.
- Option "Use my current jobs tab instead" for users who prefer that. Warn them about the reload behaviour in the options page copy.

If the monitor tab has navigated away (user clicked a job inside it), force it back to the base URL before the reload.

### 4.4 Timing model (user adjustable)

The check interval is a **setting, not a constant**. Nothing outside `core/constants.js` `DEFAULTS` may hardcode 5, 10 or 20. A change made in the popup or options applies within a second, with no extension reload.

| Setting | Range | Default | Meaning |
|---|---|---|---|
| `intervalMode` | `fixed` / `random` | `random` | `fixed`: every `minIntervalMin` exactly. `random`: uniform between min and max |
| `minIntervalMin` | 2 to 60 | 5 | Fixed interval, or the low end of the range |
| `maxIntervalMin` | `minIntervalMin` to 60 | 10 | High end of the range. Ignored in `fixed` mode |
| `freshWindowMin` | 2 to 60 | 10 | Floor of the "posted recently" window |
| `autoWidenFreshWindow` | bool | `true` | Widen the window to cover the gap between checks |
| `settleSec` | 5 to 60 | 20 | Wait after reload before reading |

**Presets** (one click, in popup and options):

| Preset | Writes |
|---|---|
| Every 3 min | `fixed`, min 3 |
| 5 to 10 min (default) | `random`, min 5, max 10 |
| Every 10 min | `fixed`, min 10 |
| Custom | reveals the sliders |

**Why 2 minutes is the floor.** A cycle takes up to 30 s (settle plus readiness) and the watchdog is 90 s. Anything shorter overlaps cycles. Below 3 minutes the options page shows a politeness warning: "Checking this often loads the page N times an hour."

**Why the fresh window must follow the interval.** A job posted one second after a check is `interval + settle` old at the next check. With a 10 minute interval and a 10 minute window it is 10.4 minutes old and **silently missed**. Revision 1 had this bug at its own default. The window is therefore widened:

```js
// src/core/schedule.js
export const CYCLE_MARGIN_MIN = 2;   // settle 20 s + readiness 10 s + slack

export const maxIntervalOf = s =>
  s.intervalMode === 'fixed' ? s.minIntervalMin : s.maxIntervalMin;

export function effectiveFreshMin(s) {
  return s.autoWidenFreshWindow
    ? Math.max(s.freshWindowMin, maxIntervalOf(s) + CYCLE_MARGIN_MIN)
    : s.freshWindowMin;
}
```

| Interval | `freshWindowMin` | Effective window |
|---|---|---|
| Every 3 min | 10 | 10 |
| 5 to 10 min | 10 | 12 |
| Every 10 min | 10 | 12 |
| Every 30 min | 10 | 32 |

A wider window never causes a repeat alert. The `seen` store is what prevents repeats. The window only stops old jobs from alerting after a long gap (sleep, Chrome closed).

**Next run time.** Pure, with `rand` injected so tests are deterministic:

```js
export const BACKOFF_LADDER_MIN = [0, 0, 10, 20, 40, 60];   // index = consecutive failures, 5+ = 60

export function nextDelayMin(s, failures, rand) {
  const lo = s.minIntervalMin, hi = maxIntervalOf(s);
  const normal = lo + rand() * (hi - lo);
  const ladder = BACKOFF_LADDER_MIN[Math.min(failures, BACKOFF_LADDER_MIN.length - 1)];
  return Math.max(normal, ladder);          // backoff never makes checks MORE frequent
}

// anchor = start of the last cycle, so cadence does not drift by the settle time
export function nextRunAt(anchorMs, delayMin, nowMs) {
  return Math.max(anchorMs + delayMin * 60000, nowMs + 30000);   // alarms floor
}

export function reloadCap(s) {                 // hourly cap never blocks the chosen interval
  return Math.max(s.maxReloadsPerHour, Math.ceil(60 / s.minIntervalMin) + 4);
}
```

**Live re-arm.** `background.js` registers `storage.onChanged` at top level. When `intervalMode`, `minIntervalMin`, `maxIntervalMin` or `enabled` changes:
- Cycle in flight: do nothing. The new timing is used when that cycle schedules its successor.
- Disabled: clear the `tick` alarm, status `PAUSED`.
- Otherwise: `when = nextRunAt(stats.lastRunMs || now, nextDelayMin(new, failures, Math.random), now)`, create the `tick` alarm at `when`, write `stats.nextRunMs`.

So switching 10 -> 3 when the last check was 4 minutes ago fires a check in 30 s. Switching 3 -> 10 pushes the next check out. The popup countdown reads `stats.nextRunMs` and updates at once.

**Overflow.** If every one of the top N jobs is unseen and inside the window, more jobs may have been posted than were read. Log note `OVERFLOW` and show a hint in the popup: "Busy right now. Shorten the interval or check more jobs."

**Pages it runs on.** The match pattern also covers job detail pages (`/freelance-jobs/<category>/<slug>-<id>`). `main.js` exits at once unless `location.pathname === '/freelance-jobs'` (R13).

**Placeholders in Phase 0.** Every file the manifest names must exist from Phase 0, even as a stub (`ui/popup.html` with a title, `ui/options.html`), so "loads with zero errors" is a meaningful check.

`minimum_chrome_version: 116` is chosen because 116 is where offscreen documents, `runtime.getContexts`, `storage.session` at 10 MB, and the modern worker keepalive behaviour are all settled. Do not go lower.

## 8. The cycle, step by step

### 8.1 Sequence

```
 ALARM "tick" fires  (or FORCE_CHECK from the popup)
   │
   ├─ 0. worker wakes
   ├─ 1. gather facts via platform/: settings, stats, lock, monitor tab, PING reply, idle state
   ├─ 2. decidePrecheck(facts)  (pure, core/cycle.js)  ──skip──▶ log, maybe backoff, scheduleNext, exit
   │
   ├─ 3. set cycleLock = { id, tabId, startedMs }      (storage.session)
   ├─ 4. arm alarm "watchdog" at +1.5 min
   ├─ 5. bump reloadsThisHour
   ├─ 6. tabs.reloadTo(tabId, BASE_URL)  (update url if it wandered, else reload bypassCache)
   └─ 7. worker exits.  Awake time ~300 ms
                       │
        ┌──────────────┘
        ▼
   PAGE RELOADS
   content/content.js  ──import()──▶  content/main.js
   ├─ pathname !== '/freelance-jobs'  → exit
   ├─ HELLO → worker replies { isMonitor, topN, settleSec, debug }
   │    isMonitor = lock exists && sender.tab.id === lock.tabId && sender.frameId === 0
   ├─ not monitor and not debug → exit  (user's own tabs are never touched)
   ├─ wait settleSec
   ├─ readiness loop: readyState complete AND (state script present OR cards >= topN), 2 s × 5
   ├─ not ready → result { ok:false, reason:'NOT_READY' }
   ├─ else parsePPH(document, topN, Date.now(), navigator.onLine)   state first, DOM fallback
   ├─ debug → console.table with ageMatchesText cross check
   └─ isMonitor → sendToWorker({ type: 'JOBS', result })
                       │
        ┌──────────────┘
        ▼
   WORKER WAKES on JOBS
   ├─ 8. isCycleSender(lock, sender, now)? else ignore (stale page, other tab, no cycle)
   ├─ 9. clear watchdog
   ├─10. result not ok → failCycle(statusForReason(reason))
   ├─11. RE-VALIDATE: jobs.map(sanitizeJob), checkGates(...)  (never trust the message)
   ├─12. pickFresh(jobs, serverTimeMs, settings, seen)  → { fresh, overflow }
   ├─13. ALERT fresh: notifications capped + 1 summary, ONE sound
   ├─14. markSeen(all top N), pruneSeen(6 h)
   ├─15. one storage.local.set: seen, lastJobs, stats, log; set badge
   ├─16. clear cycleLock
   └─17. scheduleNext(settings, failures = 0, anchor = lock.startedMs)
```

**Phase 1 behaviour.** There is no `HELLO` handler yet, so `sendToWorker` returns `null`. `main.js` treats a null reply as debug mode: parse and `console.table` on every load of the base page, send nothing. From Phase 2 the worker always answers `HELLO`.

### 8.2 PRECHECK - all reasons to skip

`decidePrecheck` is pure. `background.js` gathers the facts through `platform/` and passes them in. Every skip logs one line and always calls `scheduleNext()` so the loop never dies.

| # | Condition | Status | Backoff? |
|---|---|---|---|
| 1 | `settings.enabled === false` | `PAUSED` | No. Tick alarm is cleared, re-armed on enable |
| 2 | Last status `BLOCKED` and not resumed | `BLOCKED` | Stop entirely, no reschedule |
| 3 | `cycleLock` younger than 3 min | `RUNNING` | No, skip this tick |
| 4 | `cycleLock` older than 3 min | clear it, continue | - |
| 5 | `reloadsThisHour >= reloadCap(settings)` | `CAPPED` | Next run = top of next hour + jitter |
| 6 | `monitorTabId` missing or `tabs.get` fails | `NO_TAB` | Yes. With `autoReopenTab`, create the pinned tab and continue instead |
| 7 | `idle.queryState(60) === 'locked'` and `pauseWhenLocked` | `PAUSED` | No |
| 8 | `PING` answered with `online: false` | `OFFLINE` | Yes |
| 9 | `PING` unanswered and `self.navigator.onLine === false` | `OFFLINE` | Yes |
| 10 | `PING` unanswered, otherwise | **continue with the reload** | - |
| 11 | Tab URL unreadable or not the base path | continue, `reloadTo` navigates it back | - |

Row 10 is a rev 2 change (R11). A tab opened before the extension was installed or reloaded has no content script, so it can never answer `PING`. Rev 1 skipped such a tab forever. Now we reload anyway. If the page is truly dead, the 90 s watchdog marks the cycle `UNRESPONSIVE` and backoff applies.

**Reopen order (Phase 2).** When the monitor tab must be (re)opened, the worker creates it pinned at `about:blank`, writes the lock, then navigates it to the jobs page. The page therefore can never send `HELLO` before the lock exists.

### 8.3 Settle, done properly

20 s floor plus a readiness check, never a blind wait that then parses whatever is there. Lives in `content/main.js`.

```js
await sleep(settleSec * 1000);

let ready = isReady(document, topN);
for (let i = 0; !ready && i < LIMITS.READY_RETRIES; i++) {   // 5 × 2 s
  await sleep(LIMITS.READY_RETRY_MS);
  ready = isReady(document, topN);
}
const result = ready
  ? parsePPH(document, topN, Date.now(), navigator.onLine)
  : { ok: false, reason: 'NOT_READY' };
```

`isReady` = `readyState === 'complete'` AND (the `window.PPHReact` script exists OR at least `topN` cards exist). The state script is checked first (R6): if PeoplePerHour renames the card class, the state parser still runs.

Worst case 20 + 10 s = 30 s, well inside the 90 s watchdog. A `sleep` in the content script is fine. It lives in the page, not in the service worker.

### 8.4 Sanity gates before trusting a parse

`checkGates(jobs, serverTimeMs, nowMs, topN)` in `core/validate.js` returns a `Result` whose error names the gate, so the log says which one failed.

| Gate | Error |
|---|---|
| `jobs` is an array of exactly `topN` | `GATE_COUNT` |
| `serverTimeMs` finite and within 24 h of `nowMs` | `GATE_SERVER_TIME` |
| every `postedMs` finite | `GATE_NAN_TIME` |
| every `serverTimeMs - postedMs > -60000` | `GATE_FUTURE` |
| every `id` matches `/^\d{1,20}$/` | `GATE_ID` |
| ids unique | `GATE_DUP_ID` |

URLs are **sanitized, not gated**: a non-PeoplePerHour URL becomes `null` in `sanitizeJob`. That job still alerts, but clicking the notification opens the monitor tab instead of the URL. One odd URL must not blind the whole cycle.

Order of attempts: **state parser -> DOM parser -> `PARSE_FAILED`** (or `NO_CARDS` when there are no cards at all).
On `PARSE_FAILED`, set badge `?` and log `failures`. Two in a row: one notification saying the site layout may have changed.

The worker runs `sanitizeJob` and `checkGates` **again** on receipt (step 11). A message is data, not proof.

### 8.5 COMPARE

```js
// src/core/select.js
export function pickFresh(jobs, serverTimeMs, settings, seen) {
  const windowMs = effectiveFreshMin(settings) * 60000;
  const inWindow = j => serverTimeMs - j.postedMs < windowMs;
  const unseen   = j => !Object.hasOwn(seen, j.id);
  const fresh = jobs.filter(j =>
    j.state === 'open' && inWindow(j) && unseen(j) && passesFilters(j, settings.filters));
  const overflow = jobs.length > 0 && jobs.every(j => inWindow(j) && unseen(j));
  return { fresh, overflow };
}

export function passesFilters(j, f) {
  const hay = `${j.title} ${j.category}`.toLowerCase();
  if (f.keywordsExclude.some(k => hay.includes(k.toLowerCase()))) return false;
  if (f.keywordsInclude.length &&
      !f.keywordsInclude.some(k => hay.includes(k.toLowerCase()))) return false;
  if (f.minBudget && j.budget < f.minBudget) return false;
  if (f.maxProposals != null && j.proposals > f.maxProposals) return false;
  if (f.remoteOnly && j.locationType !== 'remote') return false;
  if (f.prefundedOnly && !j.etiquettes.prefunded) return false;
  return true;
}

export function markSeen(seen, jobs, nowMs) {         // keep first-seen time
  const next = { ...seen };
  for (const j of jobs) if (!Object.hasOwn(next, j.id)) next[j.id] = nowMs;
  return next;
}

export function pruneSeen(seen, nowMs, ttlMs) {
  return Object.fromEntries(Object.entries(seen).filter(([, t]) => nowMs - t < ttlMs));
}
```

**Mark all top N as seen, not just the fresh ones.** Otherwise a job that fails a filter today and passes it tomorrow, or a job that was just outside the window, re-enters the pool and re-alerts.

`seen` TTL (6 h) must stay larger than the largest possible effective window (62 min). `clampSettings` guarantees that.

## 10. Messaging protocol

Every message carries `type` (constants in `MSG`). Every request is wrapped in a timeout so a dead peer can never hang a cycle. The worker ignores messages whose `sender.id !== chrome.runtime.id`.

| Type | From -> To | Payload | Reply |
|---|---|---|---|
| `HELLO` | content -> worker | `{}` | `{ isMonitor, topN, settleSec, debug }` |
| `JOBS` | content -> worker | `{ result: ParseResult }` | `{ ok }` or `{ ok:false, ignored:true }` |
| `NET_BACK` | content -> worker | `{}` | `{ ok }` |
| `PING` | worker -> content | `{}` | `{ ready, online, url }` |
| `PLAY_SOUND` | worker -> offscreen | `{ file, volume }` | `{ ok }` |
| `GET_STATUS` | popup/options -> worker | `{}` | `{ stats, settings, lastJobs, effectiveFreshMin, reloadCap }` |
| `FORCE_CHECK` | popup -> worker | `{ settleSec? }` | `{ started }` |
| `SET_ENABLED` | popup -> worker | `{ enabled }` | `{ ok }` |
| `APPLY_PRESET` | popup/options -> worker | `{ preset: 'every3'\|'random5to10'\|'every10' }` | `{ ok, settings }` |
| `SAVE_SETTINGS` | options -> worker | `{ patch }` | `{ ok, settings }` (clamped) |
| `RESUME_FROM_BLOCK` | popup -> worker | `{}` | `{ ok }` |
| `OPEN_MONITOR_TAB` | popup -> worker | `{}` | `{ tabId }` |
| `TEST_SOUND` | options -> worker | `{ file, volume }` | `{ ok }` |
| `TEST_NOTIFICATION` | options -> worker | `{}` | `{ ok }` |
| `CLEAR_LOG` / `CLEAR_SEEN` / `RESET_SETTINGS` | options -> worker | `{}` | `{ ok }` |

Rev 1 `JOBS` carried a `cycleId`. Removed (R8): a reloaded content script has no way to know it. The lock's `tabId` plus `sender.tab.id` identifies the cycle instead.

**Sender guard (Phase 2).** `senderAllowed` in `core/cycle.js`: content scripts (a tab and a web page URL) may send only `HELLO`, `JOBS` and `NET_BACK`. Every other type must come from the extension's own pages (`sender.url` starts with `runtime.getURL("")`). Anything else is answered `{ ok: false, error: "FORBIDDEN" }`.

`FORCE_CHECK` is rate limited to once per 30 s and counts toward the hourly cap. `settleSec` override is honoured only when `settings.debug` is on (21.4).

Helpers live in `platform/`:

```js
// platform/tabs.js
export async function sendWithTimeout(tabId, msg, ms = 3000) {
  try {
    return await Promise.race([
      chrome.tabs.sendMessage(tabId, msg).catch(() => null),
      new Promise(r => setTimeout(() => r(null), ms))
    ]) ?? null;
  } catch { return null; }
}

// platform/runtime.js
export function onWorkerMessage(type, handler) {
  const fn = (msg, _sender, sendResponse) => {
    if (msg?.type !== type) return false;
    Promise.resolve().then(() => handler(msg)).then(sendResponse, () => sendResponse(null));
    return true;                         // keep the channel open for the async reply
  };
  chrome.runtime.onMessage.addListener(fn);
  return () => chrome.runtime.onMessage.removeListener(fn);
}
```

Always `return true` from an async `onMessage` listener, and return `false` for message types you do not handle, so other listeners can answer. Forgetting either is the number one silent bug in MV3.

## 11. Errors, backoff, and guards

### 11.1 Backoff ladder

Applied on `OFFLINE`, `UNRESPONSIVE`, `PARSE_FAILED`, `NO_TAB`. Implemented by `nextDelayMin` (4.4).

| Consecutive failures | Next delay |
|---|---|
| 0 or 1 | the normal interval |
| 2 | max(normal, 10 min) |
| 3 | max(normal, 20 min) |
| 4 | max(normal, 40 min) |
| 5+ | max(normal, 60 min) |

`max(normal, ...)` matters with a user interval: backoff may slow checks down, never speed them up. Reset to 0 on any `OK`.

### 11.2 Fast recovery on reconnect

`content/main.js` listens for the browser `online` event and sends `NET_BACK`. Worker on `NET_BACK`: if the last status was `OFFLINE`, reset failures to 0 and create the `tick` alarm at `now + 30 s` (the alarms floor). Do not fire immediately, give the network a moment.

### 11.3 Wake from sleep

`chrome.alarms` do not wake the device, and missed alarms fire once on wake. That is the behaviour we want. The fresh window stops a flood of stale alerts after a long sleep. Guard against a stale `cycleLock` left over from before sleep: on every tick, if the lock is older than 3 minutes, clear it and continue.

Re-arm on both:

```js
on.startup(bootstrap);
on.installed(bootstrap);
```

`bootstrap()` = migrate and clamp settings, create the `tick` alarm if missing (or clear it if disabled), paint the badge.

### 11.4 Hourly cap

```js
const bucket = hourBucket(nowMs);                       // core/schedule.js
if (stats.hourBucketMs !== bucket) { stats.hourBucketMs = bucket; stats.reloadsThisHour = 0; }
if (stats.reloadsThisHour >= reloadCap(settings)) -> status CAPPED, next run at bucket + 1 h
```

`reloadCap = max(maxReloadsPerHour, ceil(60 / minIntervalMin) + 4)`. At every 3 min that is 24, at every 2 min 34. The cap exists to catch a runaway bug, and must never block the interval the user deliberately chose.

### 11.5 Never do these
- Never retry a failed cycle immediately. Always go through `scheduleNext()`.
- Never run two cycles at once. The lock exists for this.
- Never parse a page that failed the readiness check.
- Never keep reloading after `BLOCKED`.
- Never `setTimeout` or `sleep` for more than 20 seconds in the service worker.
- Never make an alarm shorter than 30 s.
- Never let backoff produce a shorter delay than the user's interval.

## 12. Design system

The extension has three surfaces: **popup**, **options**, **notification**. They must feel like one product. One token file, `ui/tokens.css`, imported by both HTML pages.

### 12.1 Principles

1. **Glanceable first.** The popup answers one question in under a second: is it watching, and did anything just land? Everything else is secondary.
2. **Status is colour plus shape plus text.** Never colour alone. A colour blind user and a user glancing sideways both need to read it.
3. **Calm by default, loud only when it matters.** Neutral greys at rest. Accent colour reserved for a live fresh job.
4. **No layout shift.** The popup opens at a fixed size and never jumps as data arrives. Skeleton rows, not spinners that resize.
5. **Dark mode is not optional.** Most people who watch job boards at 2 am have dark mode on.

### 15.2 Sound

Service workers have no DOM and cannot play audio. Offscreen document is the only path.

```js
// src/platform/offscreen.js
let creating = null;                                   // two alerts in one wake must not create twice

export async function playSound(file, volume) {
  try {
    const existing = await chrome.runtime.getContexts({ contextTypes: ['OFFSCREEN_DOCUMENT'] });
    if (!existing.length) {
      creating ??= chrome.offscreen.createDocument({
        url: 'offscreen/offscreen.html',
        reasons: ['AUDIO_PLAYBACK'],
        justification: 'Play an alert tone when a new freelance job is posted.'
      }).finally(() => { creating = null; });
      await creating;
    }
    const msg = { type: 'PLAY_SOUND', file, volume };
    // The document's module script can lag creation slightly. One retry, no loop.
    let reply = await chrome.runtime.sendMessage(msg).catch(() => null);
    if (!reply) {
      await new Promise(r => setTimeout(r, 150));
      reply = await chrome.runtime.sendMessage(msg).catch(() => null);
    }
    return !!reply?.ok;
  } catch { return false; }
}
```

Do **not** call `closeDocument()` yourself. An `AUDIO_PLAYBACK` offscreen document auto-closes 30 seconds after playback ends. Reuse it on the next alert if it is still alive.

`offscreen/offscreen.js` (loaded as `<script type="module">`):
```js
import { onWorkerMessage, getURL } from '../platform/runtime.js';
import { SOUND_FILES } from '../core/constants.js';

onWorkerMessage('PLAY_SOUND', async ({ file, volume }) => {
  if (!SOUND_FILES.includes(file)) return { ok: false };          // allow list only
  const a = new Audio(getURL(file));
  a.volume = Math.max(0, Math.min(1, Number(volume) || 0));
  try { await a.play(); return { ok: true }; }
  catch { return { ok: false }; }                                  // autoplay rejection, see Test sound
});
```

**Sound design**
| File | Character | Length | Used for |
|---|---|---|---|
| `chime.wav` | Two soft sine notes, rising (E5 -> A5), fade in/out | 0.6 s | Default. Pleasant at 2 am |
| `ping.wav` | Single clean ping (A5), exponential decay | 0.3 s | Minimal |
| `alarm.wav` | Three sharp notes (A5 A5 E6) | 1.2 s | Budget over the high-value threshold |

Play **once per cycle**, not once per job. Five jobs must not produce five overlapping chimes. If any fresh job is high value, play `alarm.wav`, otherwise play the chosen default.

**Source (R14).** `tools/make-sounds.mjs` synthesises the tones and writes 8-bit mono 22,050 Hz PCM WAV with a 5 ms fade at every note edge (no clicks). Only Node built-ins. Each file stays under 40 KB. The output is committed so loading unpacked never requires running a tool. A user may drop their own `.wav`, `.mp3` or `.ogg` into `src/sounds/` and add it to `SOUND_FILES` in constants. `clampSettings` rejects any path not in that list, so the offscreen page can never be told to load an arbitrary URL.

## 17. Accessibility

- Every interactive element reachable by keyboard, in visual order. No positive `tabindex`.
- Visible focus ring everywhere: `outline: 2px solid var(--accent); outline-offset: 2px`. Never `outline: none` without a replacement.
- Status is never colour only. Dot shape + text label always accompany it.
- Contrast: body text at least 4.5:1, large text and UI borders at least 3:1, in **both** themes. Verify with a contrast checker, do not eyeball it.
- Job cards are real `<a>` elements so screen readers announce them as links and the middle-click / ctrl-click behaviour is free.
- `aria-live="polite"` on the popup status line so a screen reader announces a status change without interrupting.
- Range inputs have visible numeric values next to them, and `aria-valuetext` with the unit ("7 minutes").
- Respect `prefers-reduced-motion`: kill the pulse animation and all transitions.
- Minimum hit target 32x32 px in the popup, 40x40 px in options.

## 18. Security and privacy

- **No remote code.** Everything ships in the package. MV3 forbids remote scripts and the CSP in the manifest enforces `script-src 'self'`.
- **No network calls of our own.** The extension never `fetch()`es anything. It only reads a page the user's browser already loaded.
- **No credentials.** It never reads cookies, never touches login forms, never submits anything.
- **No telemetry.** Nothing leaves the machine. Say this plainly in the options page and the README.
- **Least privilege.** `host_permissions` is scoped to `peopleperhour.com` only, not `<all_urls>`.
- **Untrusted page data.** Everything the content script reads is attacker-controllable in principle. Therefore:
  - Never `innerHTML` a job title. Use `textContent`.
  - Validate `job.url` with `isPphUrl` (parsed `URL`: `https:`, host exactly `www.peopleperhour.com`, no credentials) before storing or opening it. Plain `startsWith` is not enough for stored URLs.
  - Re-sanitize and re-gate every `JOBS` message in the worker. Ignore messages from other extensions or from tabs that are not the locked monitor tab.
  - Sound file paths come only from the `SOUND_FILES` allow list.
- **Enforced, not hoped for.** `tests/purity.test.js` (U10) fails the build on `innerHTML`, `eval`, `fetch`, stray URLs, `chrome.*` outside `platform/`, `<all_urls>`, or a changed CSP.
- **Local only.** Never packed, never published. The repo is private. `.gitignore` covers `.env*`, `*.pem` and `*.crx`.
  - Clamp all numbers, coerce all strings, cap all lengths before storing.
- **Terms.** Personal monitoring of a page you are already entitled to view is normal. Automated interaction is a different thing. This extension deliberately stays on the reading side of that line. Read PPH's terms before sharing the extension with anyone else.

## 19. Performance budget

| Metric | Budget | Why |
|---|---|---|
| Service worker awake time per cycle | under 500 ms | The inverted design makes this easy |
| Content script parse time | under 50 ms | It is one regex and one `JSON.parse` on 190 KB |
| Popup first paint | under 100 ms | Read from `storage.local`, render, done. No network |
| Package size | under 1 MB | Three small MP3s and five PNGs are the bulk |
| `storage.local` used | under 200 KB | With pruning, nowhere near the 10 MB quota |
| Page loads per hour | 6 to 12 typical, 20 hard cap | Politeness |

`JSON.parse` on a 190 KB string is roughly 1 to 3 ms. Do not prematurely optimise it, but do it **once** per cycle and cache the result, never inside a loop.

## 20. MV3 best practices checklist

Tick every box before calling v1 done.

**Service worker**
- [ ] No global mutable state relied on across events. Everything in `chrome.storage`.
- [ ] No `setTimeout` or `setInterval` longer than 20 s in the worker. Use `chrome.alarms`.
- [ ] No `await sleep(...)` for the settle window in the worker. It lives in the content script.
- [ ] All listeners registered **synchronously at the top level**, not inside an `async` function or a promise callback. Late registration means missed events on a cold start.
- [ ] `"type": "module"` in the manifest so `import` works.
- [ ] Every `async` `onMessage` listener either returns `true` or uses the promise form.
- [ ] `onInstalled` and `onStartup` both re-arm the alarm and merge settings.
- [ ] Every `chrome.*` callback path checks `chrome.runtime.lastError` or uses `.catch()`.

**Alarms**
- [ ] No alarm below 0.5 minutes. Chrome warns and ignores it.
- [ ] Watchdog alarm cleared on success, so it never fires spuriously.
- [ ] Do not depend on `persistAcrossSessions` (Chrome 150+). Re-arm on startup instead.

**Storage**
- [ ] Reads and writes are batched. One `get`, one `set` per cycle, not ten.
- [ ] `seen` store pruned every cycle.
- [ ] `log` capped at 50 entries.
- [ ] Settings merged on update, never replaced.

**Content script**
- [ ] Assumes it may run on a page that is already half rendered.
- [ ] Never touches page globals. Reads script `textContent` instead.
- [ ] Guards every selector with a null check. The site will change.
- [ ] Prefix class matching only (`[class*="..."]`), never full hashed class names.
- [ ] Cleans up its own listeners on `pagehide`.

**Offscreen**
- [ ] Checks `getContexts` before creating. Only one may exist.
- [ ] Does not manually close an `AUDIO_PLAYBACK` document. It self-closes after 30 s.
- [ ] Autoplay rejection is caught and ignored.

**UI**
- [ ] Popup renders from cached storage instantly, then updates. No blank flash.
- [ ] Fixed popup width. No layout shift.
- [ ] Dark mode via `prefers-color-scheme`, tokens only, no hardcoded hex in components.
- [ ] `prefers-reduced-motion` respected.
- [ ] No `innerHTML` with site data anywhere.

**Packaging**
- [ ] No remote scripts, no CDN, no `eval`, no `new Function`.
- [ ] `minimum_chrome_version` set.
- [ ] Version bumped on every reload you want to distinguish in the log.

**Timing (rev 2)**
- [ ] No interval, window or settle value hardcoded outside `DEFAULTS`.
- [ ] `storage.onChanged` re-arms the tick alarm when timing settings change.
- [ ] Every settings write goes through `clampSettings`.
- [ ] Scheduling anchors on cycle start, floors at 30 s, and backoff never shortens the user interval.
- [ ] `effectiveFreshMin` covers `maxInterval + 2`.

**Tests and structure (rev 2)**
- [ ] `npm test` and `npm run coverage` green. U1 has its control assertion.
- [ ] U10 purity test green: no `chrome.*` outside `platform/` (plus the one bootstrap line).
- [ ] Every file in the content script import graph is in `web_accessible_resources`.

### 25.2 `src/core/time.js`

```js
const MIN = 60000, HOUR = 3600000, DAY = 86400000;
export const UNKNOWN_AGE_MS = 99 * DAY;                 // finite, never fresh

const POSTED_RE = /^\d{4}-\d{2}-\d{2} \d{2}:\d{2}:\d{2}$/;

/** posted_dt is a UTC wall clock with a space and no zone. See 3.5. */
export function toUtcMs(postedDt) {
  if (typeof postedDt !== 'string' || !POSTED_RE.test(postedDt)) return NaN;
  return Date.parse(postedDt.replace(' ', 'T') + 'Z');
}

export const ageMinutes = (nowMs, postedMs) => (nowMs - postedMs) / MIN;

/** moment.js fromNow() text -> representative age in ms. See 3.6. */
export function relToMs(text) {
  const t = String(text ?? '').trim().replace(/\s+/g, ' ').toLowerCase();
  if (t === 'a few seconds ago' || t === 'in a few seconds' || t === 'just now') return 0;
  if (t === 'a minute ago') return MIN;
  if (t === 'an hour ago')  return HOUR;
  if (t === 'a day ago')    return DAY;
  const m = t.match(/^(\d{1,4}) (minute|hour|day)s? ago$/);
  if (!m) return UNKNOWN_AGE_MS;
  return Number(m[1]) * { minute: MIN, hour: HOUR, day: DAY }[m[2]];
}

/** Does our computed age agree with the page's rounded text? */
export function ageMatchesText(ageMs, text, toleranceMin = 1) {
  const shown = relToMs(text);
  if (shown === UNKNOWN_AGE_MS || !Number.isFinite(ageMs)) return false;
  const tolerance = shown >= HOUR ? 30 * MIN : toleranceMin * MIN;
  return Math.abs(ageMs - shown) <= tolerance;
}

export function formatAge(ageMs) {
  if (!Number.isFinite(ageMs) || ageMs < 0) return '?';
  if (ageMs < MIN)  return '<1 min';
  if (ageMs < HOUR) return `${Math.round(ageMs / MIN)} min`;
  if (ageMs < DAY)  return `${Math.round(ageMs / HOUR)} h`;
  return `${Math.round(ageMs / DAY)} d`;
}
```

```js
const PPH_HOST = 'www.peopleperhour.com';
const DAY = 86400000;

  const e = j.etiquettes && typeof j.etiquettes === 'object' ? j.etiquettes : {};

    id: str(j.id, 20),
    title: str(j.title, 300).trim(),
    url: isPphUrl(j.url) ? j.url : null,
    postedMs: Number(j.postedMs),                       // not clamped: NaN must reach the gate
    ageMin: Number(j.ageMin),
    budget: clamp(Number(j.budget), 0, 1e7),
    currency: str(j.currency, 3).toUpperCase().replace(/[^A-Z]/g, ''),
    projectType: j.projectType === 'hourly' ? 'hourly' : 'fixed_price',
    proposals: Math.round(clamp(Number(j.proposals), 0, 10000)),
    state: str(j.state, 20),
    locationType: j.locationType === 'remote' ? 'remote' : 'onsite',
    category: str(j.category, 100),
    etiquettes: {

    }
  };
}

/** @returns {Result} error names the failing gate. See 8.4. */
export function checkGates(jobs, serverTimeMs, nowMs, topN) {
  if (!Array.isArray(jobs) || jobs.length !== topN) return err('GATE_COUNT');
  if (!Number.isFinite(serverTimeMs) || Math.abs(serverTimeMs - nowMs) > DAY) return err('GATE_SERVER_TIME');
  if (!jobs.every(j => Number.isFinite(j.postedMs))) return err('GATE_NAN_TIME');
  if (!jobs.every(j => serverTimeMs - j.postedMs > -60000)) return err('GATE_FUTURE');
  if (!jobs.every(j => /^\d{1,20}$/.test(j.id))) return err('GATE_ID');
  if (new Set(jobs.map(j => j.id)).size !== topN) return err('GATE_DUP_ID');
```

### 25.4 `src/core/parser.js`

```js
import { toUtcMs, relToMs } from './time.js';
import { sanitizeJob } from './validate.js';

export const MAX_SCRIPT_CHARS = 2_000_000;
const STATE_RE = /window\.PPHReact\.initialState\s*=\s*([\s\S]*?);\s*window\.PPHReact\.data\s*=/;
const SERVER_TIME_RE = /window\.PPHReact\.serverTime\s*=\s*['"](\d{12,14})['"]/;

/** Slice the JSON out of the inline script text. Never parses the non-JSON `data` literal. */
export function extractStateJson(raw) {
  if (typeof raw !== 'string' || raw.length > MAX_SCRIPT_CHARS) return null;
  const m = raw.match(STATE_RE);
  const serverTimeMs = Number((raw.match(SERVER_TIME_RE) || [])[1]);
  if (!m || !Number.isFinite(serverTimeMs)) return null;
  return { json: m[1], serverTimeMs };
}

/** @returns {Job[] | null} top N from freelanceJobs.main only */
export function jobsFromState(state, serverTimeMs, topN) {
  const refs = state?.freelanceJobs?.main?.data;
  const projects = state?.entities?.projects;
  if (!Array.isArray(refs) || !projects || typeof projects !== 'object') return null;

  const jobs = [];
  for (const ref of refs.slice(0, topN)) {
    const a = projects[ref?.id]?.attributes;
    if (!a) return null;
    const postedMs = toUtcMs(a.posted_dt);
    jobs.push(sanitizeJob({
      id: a.proj_id ?? ref.id,
      title: a.title,
      url: a.url,
      postedMs,
      ageMin: (serverTimeMs - postedMs) / 60000,
      budget: a.budget,
      currency: a.currency,
      projectType: a.project_type,
      proposals: a.proposalCount,
      state: a.item_state,
      locationType: a.location_type,
      category: a.category?.cate_name,
      etiquettes: a.etiquettes
    }));
  }
  return jobs;
}

/** Numeric project id at the end of a job URL. Same key as proj_id (R12). */
export function idFromUrl(href) {
  const m = String(href ?? '').match(/(\d{5,20})(?:[/?#]|$)/);
  return m ? m[1] : '';
}

const CURRENCY = { '£': 'GBP', '$': 'USD', '€': 'EUR' };

/** @param {CardData[]} cards  @returns {Job[] | null} */
export function jobsFromCards(cards, nowMs, topN) {
  if (!Array.isArray(cards) || cards.length < topN) return null;
  return cards.slice(0, topN).map(c => {
    const footer = Array.isArray(c?.footer) ? c.footer : [];
    const price = String(c?.price ?? '');
    const ageMs = relToMs(footer[0]);
    return sanitizeJob({
      id: idFromUrl(c?.href),
      title: c?.title,
      url: c?.href,
      postedMs: nowMs - ageMs,
      ageMin: ageMs / 60000,
      budget: parseFloat(price.replace(/[^\d.]/g, '')),
      currency: CURRENCY[price.trim()[0]] ?? '',
      projectType: /\/\s*h(ou)?r/i.test(price) ? 'hourly' : 'fixed_price',
      proposals: parseInt(footer[1], 10),
      state: 'open',
      locationType: /remote/i.test(footer[2] ?? '') ? 'remote' : 'onsite',
      category: '',
      etiquettes: Object.fromEntries((c?.badges ?? [])
        .map(b => [String(b).replace(/[^a-z]/gi, '').toLowerCase(), true]))
    });
  });
}
```

### 25.5 `src/content/dom.js` (the only DOM reader, no decisions)

```js
import { SELECTORS, BLOCKED_TITLE_RE } from '../core/constants.js';
import { extractStateJson, jobsFromState, jobsFromCards } from '../core/parser.js';
import { checkGates } from '../core/validate.js';
import { attempt } from '../core/result.js';

// SELECTORS = { CARD: '[class*="item--container"]', TITLE_LINK: 'a[class*="item__url"]',
//   PRICE: '[class*="card__price"]', FOOTER_SPANS: '[class*="card__footer-left"] span',
//   BADGE: '[class*="etiquettes--"]', CAPTCHA_FRAME: 'iframe[src*="captcha"], iframe[src*="challenge"]' }
// BLOCKED_TITLE_RE = /just a moment|attention required|access denied|sign in|log in/i

export function findStateScriptText(doc) {
  for (const s of doc.querySelectorAll('script:not([src])')) {
    const t = s.textContent || '';
    if (t.trimStart().startsWith('window.PPHReact')) return t;
  }
  return null;
}

/** @returns {CardData[]} */
export function readCards(doc, max) {
  return [...doc.querySelectorAll(SELECTORS.CARD)].slice(0, max).map(c => {
    const a = c.querySelector(SELECTORS.TITLE_LINK);
    return {
      href: a?.href || '',
      title: (a?.textContent || '').trim(),
      price: (c.querySelector(SELECTORS.PRICE)?.textContent || '').trim(),
      footer: [...c.querySelectorAll(SELECTORS.FOOTER_SPANS)].map(s => (s.textContent || '').trim()),
      badges: [...c.querySelectorAll(SELECTORS.BADGE)].map(b => (b.textContent || '').trim())
    };
  });
}

export function isReady(doc, topN) {
  return doc.readyState === 'complete' &&
    (findStateScriptText(doc) !== null || doc.querySelectorAll(SELECTORS.CARD).length >= topN);
}

export function isBlocked(doc) {
  if (findStateScriptText(doc) !== null) return false;
  if (doc.querySelectorAll(SELECTORS.CARD).length > 0) return false;
  return BLOCKED_TITLE_RE.test(doc.title || '') || !!doc.querySelector(SELECTORS.CAPTCHA_FRAME);
}

/** @returns {ParseResult} state first, DOM fallback (R6) */
export function parsePPH(doc, topN, nowMs, online) {
  if (!online) return { ok: false, reason: 'OFFLINE' };
  if (doc.readyState !== 'complete') return { ok: false, reason: 'NOT_READY' };
  if (isBlocked(doc)) return { ok: false, reason: 'BLOCKED' };

  const failures = [];
  const extracted = extractStateJson(findStateScriptText(doc));
  if (extracted) {
    const parsed = attempt(() => JSON.parse(extracted.json));
    const jobs = parsed.ok ? jobsFromState(parsed.value, extracted.serverTimeMs, topN) : null;
    const gate = checkGates(jobs, extracted.serverTimeMs, nowMs, topN);
    if (gate.ok) return { ok: true, source: 'state', serverTimeMs: extracted.serverTimeMs, jobs, failures };
    failures.push(`state:${parsed.ok ? gate.error : 'JSON'}`);
  } else {
    failures.push('state:MISSING');
  }

  const cards = readCards(doc, topN);
  const jobs = jobsFromCards(cards, nowMs, topN);
  const gate = checkGates(jobs, nowMs, nowMs, topN);
  if (gate.ok) return { ok: true, source: 'dom', serverTimeMs: nowMs, jobs, failures };
  failures.push(`dom:${gate.error}`);

  return { ok: false, reason: cards.length ? 'PARSE_FAILED' : 'NO_CARDS', failures };
}
```

```js
import { DEFAULTS, LIMITS, MSG, BASE_PATH } from '../core/constants.js';
import { formatAge, ageMatchesText } from '../core/time.js';
import { idFromUrl } from '../core/parser.js';
import { sendToWorker, onWorkerMessage } from '../platform/runtime.js';
import { parsePPH, isReady, readCards } from './dom.js';

const sleep = ms => new Promise(r => setTimeout(r, ms));

export async function start() {
  if (location.pathname !== BASE_PATH) return;                 // '/freelance-jobs' only (R13)

  const offPing = onWorkerMessage(MSG.PING, () =>
    ({ ready: isReady(document, 1), online: navigator.onLine, url: location.href }));
  const onOnline = () => sendToWorker({ type: MSG.NET_BACK });
  addEventListener('online', onOnline);
  addEventListener('pagehide', () => { offPing(); removeEventListener('online', onOnline); }, { once: true });

  const hello = await sendToWorker({ type: MSG.HELLO }, LIMITS.MESSAGE_TIMEOUT_MS);
  const debug = hello === null || hello.debug === true;           // null = Phase 1, no worker handler
  if (hello && !hello.isMonitor && !debug) return;                 // not our tab (R13)

  const topN = hello?.topN ?? DEFAULTS.topN;
  await sleep((hello?.settleSec ?? DEFAULTS.settleSec) * 1000);

  let ready = isReady(document, topN);
  for (let i = 0; !ready && i < LIMITS.READY_RETRIES; i++) {
    await sleep(LIMITS.READY_RETRY_MS);
    ready = isReady(document, topN);
  }
  const result = ready
    ? parsePPH(document, topN, Date.now(), navigator.onLine)
    : { ok: false, reason: 'NOT_READY', failures: [] };

  if (debug) logCrossCheck(result);
  if (hello?.isMonitor) await sendToWorker({ type: MSG.JOBS, result }, LIMITS.MESSAGE_TIMEOUT_MS);
}

/** Phase 1 acceptance: our age vs the page's own text, per job id. */
function logCrossCheck(result) {
  if (!result.ok) return console.warn('[PPH Job Radar]', result.reason, result.failures);
  const pageText = new Map(readCards(document, 20).map(c => [idFromUrl(c.href), c.footer[0] ?? '']));
  console.log(`[PPH Job Radar] source=${result.source}`, result.failures);
  console.table(result.jobs.map(j => {
    const text = pageText.get(j.id) ?? '(card not found)';
    return { id: j.id, age: formatAge(j.ageMin * 60000), pageText: text,
             match: ageMatchesText(j.ageMin * 60000, text), title: j.title.slice(0, 60) };
  }));
}
```

## 26. Appendix B: background skeleton

Wiring only. Every decision is a call into `core/`, every Chrome call goes through `platform/`. Handlers not shown follow the same pattern.

```js
// src/background.js  - "type": "module"
import { DEFAULTS, LIMITS, MSG, STATUS, ALARM, BASE_URL } from './core/constants.js';
import { mergeSettings, clampSettings, timingChanged, applyPreset } from './core/settings.js';
import { nextDelayMin, nextRunAt, reloadCap, hourBucket, effectiveFreshMin } from './core/schedule.js';
import { decidePrecheck, isCycleSender, statusForReason, backoffApplies } from './core/cycle.js';
import { pickFresh, markSeen, pruneSeen } from './core/select.js';
import { sanitizeJob, checkGates } from './core/validate.js';
import * as on from './platform/events.js';
import * as store from './platform/storage.js';
import * as alarms from './platform/alarms.js';
import * as tabs from './platform/tabs.js';
import * as idle from './platform/idle.js';
import { alertJobs } from './platform/notifications.js';
import { paint } from './platform/badge.js';

const HANDLERS = {
  [MSG.HELLO]:        onHello,
  [MSG.JOBS]:         onJobs,
  [MSG.NET_BACK]:     onNetBack,
  [MSG.GET_STATUS]:   buildStatus,
  [MSG.FORCE_CHECK]:  () => runCycle('force'),
  [MSG.APPLY_PRESET]: ({ preset }) => saveSettings(s => applyPreset(s, preset)),
  [MSG.SAVE_SETTINGS]:({ patch })  => saveSettings(s => mergeSettings(s, patch)),
  [MSG.SET_ENABLED]:  ({ enabled }) => saveSettings(s => ({ ...s, enabled: !!enabled })),
  // ... RESUME_FROM_BLOCK, OPEN_MONITOR_TAB, TEST_SOUND, TEST_NOTIFICATION, CLEAR_* (section 10)
};

// ---- listeners registered SYNCHRONOUSLY at top level (section 20) ----
on.installed(bootstrap);
on.startup(bootstrap);
on.alarm(onAlarm);
on.message(HANDLERS);            // platform wraps: own-sender check, return true, never throws
on.tabRemoved(onTabRemoved);
on.notificationClicked(onNotifClick);
on.storageChanged(onStorageChanged);

async function bootstrap() {
  const { settings } = await store.getLocal(['settings']);
  const s = clampSettings(mergeSettings(DEFAULTS, settings));
  await store.setLocal({ settings: s });
  if (!s.enabled) await alarms.clear(ALARM.TICK);
  else if (!(await alarms.get(ALARM.TICK))) await scheduleNext(s, 0, Date.now());
  await paintFromStats();
}

async function onAlarm({ name }) {
  if (name === ALARM.TICK)     return runCycle('alarm');
  if (name === ALARM.WATCHDOG) return failCycle('UNRESPONSIVE');
}

async function scheduleNext(settings, failures, anchorMs) {
  const now = Date.now();
  const when = nextRunAt(anchorMs, nextDelayMin(settings, failures, Math.random), now);
  await alarms.createAt(ALARM.TICK, when);
  await store.patchLocal('stats', { nextRunMs: when, consecutiveFailures: failures });
}

async function runCycle(trigger) {
  const now = Date.now();
  const { settings, stats = {} } = await store.getLocal(['settings', 'stats']);
  const { cycleLock, monitorTabId } = await store.getSession(['cycleLock', 'monitorTabId']);
  const tab = monitorTabId != null ? await tabs.get(monitorTabId) : null;
  const ping = tab ? await tabs.sendWithTimeout(tab.id, { type: MSG.PING }, LIMITS.MESSAGE_TIMEOUT_MS) : null;

  const decision = decidePrecheck({
    settings, stats, cycleLock, tab, ping, now, trigger,
    reloadCap: reloadCap(settings), hourBucketMs: hourBucket(now),
    workerOnline: self.navigator.onLine,
    idleState: settings.pauseWhenLocked ? await idle.queryState(60) : 'active'
  });
  if (decision.action === 'skip') return skipCycle(decision, settings, stats, now);

  const tabId = decision.action === 'reopen' ? await tabs.createPinned(BASE_URL) : tab.id;
  if (tabId == null) return failCycle('NO_TAB');
  if (decision.action === 'reopen') await store.setSession({ monitorTabId: tabId });

  await store.setSession({ cycleLock: { id: `c-${now}`, tabId, startedMs: now } });
  await alarms.createIn(ALARM.WATCHDOG, LIMITS.WATCHDOG_MIN);          // 1.5
  await store.patchLocal('stats', decision.statsPatch);                 // lastRunMs, reload counter, RUNNING
  await paint(STATUS.RUNNING);
  const r = await tabs.reloadTo(tabId, BASE_URL);                       // navigate back if wandered
  if (!r.ok) return failCycle('NO_TAB');
  return { started: true };
  // worker may now be terminated. content/main.js will send JOBS.
}

async function onHello(_msg, sender) {
  const { settings } = await store.getLocal(['settings']);
  const { cycleLock } = await store.getSession(['cycleLock']);
  return {
    isMonitor: isCycleSender(cycleLock, sender, Date.now()),
    topN: settings.topN, settleSec: settings.settleSec, debug: settings.debug
  };
}

async function onJobs({ result }, sender) {
  const now = Date.now();
  const { cycleLock } = await store.getSession(['cycleLock']);
  if (!isCycleSender(cycleLock, sender, now)) return { ok: false, ignored: true };
  await alarms.clear(ALARM.WATCHDOG);

  if (!result?.ok) return failCycle(statusForReason(result?.reason), result?.failures);

  const { settings, seen = {}, stats = {}, log = [] } =
    await store.getLocal(['settings', 'seen', 'stats', 'log']);

  // Re-validate: a message is data, not proof (8.4)
  const jobs = Array.isArray(result.jobs) ? result.jobs.map(sanitizeJob) : [];
  const gate = checkGates(jobs, Number(result.serverTimeMs), now, settings.topN);
  if (!gate.ok) return failCycle('PARSE_FAILED', [`worker:${gate.error}`]);

  const { fresh, overflow } = pickFresh(jobs, result.serverTimeMs, settings, seen);
  if (fresh.length) await alertJobs(fresh, settings);                  // caps, summary, one sound

  const note = `${fresh.length} fresh, window ${effectiveFreshMin(settings)} min${overflow ? ', OVERFLOW' : ''}`;
  await store.setLocal({                                                 // one write for the cycle
    seen: pruneSeen(markSeen(seen, jobs, now), now, LIMITS.SEEN_TTL_MS),
    lastJobs: jobs,
    stats: { ...stats, status: STATUS.OK, consecutiveFailures: 0, consecutiveParseFailures: 0,
             totalAlerts: (stats.totalAlerts ?? 0) + fresh.length,
             unreadAlerts: (stats.unreadAlerts ?? 0) + fresh.length },
    log: [{ ts: now, status: STATUS.OK, source: result.source, note, failures: result.failures ?? [] },
          ...log].slice(0, LIMITS.LOG_MAX)
  });
  await store.removeSession('cycleLock');
  await paintFromStats();
  await scheduleNext(settings, 0, cycleLock.startedMs);
  return { ok: true };
}

async function failCycle(status, failures = []) {
  const now = Date.now();
  const { settings, stats = {} } = await store.getLocal(['settings', 'stats']);
  const { cycleLock } = await store.getSession(['cycleLock']);
  await alarms.clear(ALARM.WATCHDOG);
  await store.removeSession('cycleLock');
  const failures_ = backoffApplies(status) ? (stats.consecutiveFailures ?? 0) + 1 : 0;
  await appendLog({ ts: now, status, note: '', failures });              // + stats.status, parse failure count
  await paint(status);
  if (status === STATUS.BLOCKED) { await alarms.clear(ALARM.TICK); return notifyBlockedOnce(); }
  await scheduleNext(settings, failures_, cycleLock?.startedMs ?? now);
}

/** Live re-arm when the user changes the interval (4.4). */
async function onStorageChanged(changes, area) {
  if (area !== 'local' || !changes.settings) return;
  const { oldValue, newValue } = changes.settings;
  if (!timingChanged(oldValue, newValue)) return;
  const s = clampSettings(mergeSettings(DEFAULTS, newValue));
  if (!s.enabled) { await alarms.clear(ALARM.TICK); return paint(STATUS.PAUSED); }
  const { cycleLock } = await store.getSession(['cycleLock']);
  if (cycleLock) return;                                    // applied when this cycle schedules the next
  const { stats = {} } = await store.getLocal(['stats']);
  await scheduleNext(s, stats.consecutiveFailures ?? 0, stats.lastRunMs || Date.now());
}

async function saveSettings(update) {
  const { settings } = await store.getLocal(['settings']);
  const next = clampSettings(update(mergeSettings(DEFAULTS, settings)));
  await store.setLocal({ settings: next });                 // triggers onStorageChanged
  return { ok: true, settings: next };
}

// paintFromStats, notifyBlockedOnce: same pattern, see sections 8, 10, 11, 15.
```
